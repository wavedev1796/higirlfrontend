# HG-F3-019 - Navbar del dashboard estilo Wave + colapso responsive

## Resumen

Se rediseñó la barra de navegación del dashboard para que se comporte como la de
[thewavesea.com](https://thewavesea.com/): pegada al borde superior, de ancho
completo y `fixed`, transparente arriba y con fondo blanco translúcido + blur +
sombra al hacer scroll. Además se corrigió el comportamiento responsive: el nav
horizontal ya no queda apretado ni parte el texto en dos líneas en anchos
intermedios, sino que colapsa a la barra inferior antes de romperse.

## Objetivo

- Que la barra superior se vea igual que la de Wave y cambie de forma suave al
  hacer scroll.
- Que "por mucho que se reduzca la ventana se vea bien": sin iconos/textos
  amontonados ni etiquetas partidas en dos líneas.

## Alcance Implementado

### Estilo tipo Wave (scroll)

`.dashboard-header` pasó de "isla flotante" (`position: sticky`, con márgenes y
bordes redondeados) a `position: fixed` pegado al borde, ancho completo y sin
redondeo:

| | Arriba (top) | Con scroll (>20px) |
|---|---|---|
| Fondo | transparente | `var(--glass-bg)` |
| Blur | ninguno | `blur(16px)` |
| Sombra | ninguna | `var(--shadow-glass)` |
| Bordes | `0` | `0` |
| Padding vertical | `1.1rem` | `0.65rem` |

La clase `.scrolled` y su hook de scroll (umbral 20px) ya existían en
`(dashboard)/layout.tsx` y se reutilizan sin cambios. Como el header es `fixed`,
se agregó `padding-top` a `.dashboard-main` para que el contenido no quede
tapado.

Diseño previo aprobado en:
`docs/superpowers/specs/2026-07-09-wave-navbar-scroll-design.md` y plan en
`docs/superpowers/plans/2026-07-09-wave-navbar-scroll.md`.

### Colapso responsive

- `white-space: nowrap` en los links del nav (`.dashboard-nav nav a`) y en el
  lockup de marca (`.brand-lockup`) → ni "Mi Perfil" ni "Hi Girl" se parten en
  dos líneas.
- El punto de corte que oculta el nav horizontal y muestra la barra inferior
  (`.bottom-nav`) subió de `max-width: 767px` a `max-width: 1024px`, eliminando
  la franja intermedia donde el nav superior quedaba amontonado.

## Archivos Modificados

```text
src/styles/layouts.css        (.dashboard-header, .dashboard-main, nav responsive)
src/styles/components.css      (.brand-lockup: white-space nowrap)
```

`(dashboard)/layout.tsx` no requirió cambios (el hook de scroll ya existía).

## Criterios de Aceptación

- [x] La barra queda pegada al borde, ancho completo, sin redondeo.
- [x] Transparente arriba; blanca + blur + sombra al hacer scroll.
- [x] El contenido no queda tapado por el header fijo.
- [x] En anchos reducidos el nav colapsa a la barra inferior sin quedar apretado
      ni partir textos.

## Notas

- El punto de corte a 1024px es un valor estándar de tablet; el nav horizontal
  solo se muestra en pantallas >1024px donde cabe holgado. Ajustable si aparece
  alguna franja apretada entre 1024–1280px.
