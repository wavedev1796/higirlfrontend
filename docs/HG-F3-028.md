# HG-F3-028 - Eliminar el endpoint muerto AUTH.ME

## Resumen

Se quitó la entrada `AUTH.ME` (`/auth/perfil`) del catálogo de endpoints, como
parte de la unificación del flujo de perfil en el backend (TICKET-019).

## Objetivo

Que exista una sola forma de obtener el perfil propio y que el catálogo de
endpoints no anuncie rutas que ya no existen.

## Contexto

El backend exponía dos endpoints para "mi perfil" con proyecciones distintas:
`GET /auth/perfil` y `GET /perfil/me`. Al eliminar el duplicado se revisó qué
usaba el frontend.

Resultado de la verificación: **`API_ENDPOINTS.AUTH.ME` estaba definido pero no
se usaba en ningún componente ni hook.** `authService.getProfile()` ya apuntaba
a `API_ENDPOINTS.PROFILE.ME`. Era una entrada muerta del catálogo, así que
eliminar el endpoint en el backend no rompió nada del cliente.

## Alcance Implementado

- **`endpoints.ts`:** se elimina `AUTH.ME`. `PROFILE.ME` (`/perfil/me`) queda
  como única ruta para el perfil propio.

No hubo más cambios: ningún componente, hook ni servicio la referenciaba.

## Archivos Modificados

```text
src/infrastructure/api/endpoints.ts   (elimina AUTH.ME)
```

## Criterios de Aceptación

- [x] `AUTH.ME` ya no existe en el catálogo de endpoints.
- [x] No queda ninguna referencia a `/auth/perfil` en `src/`.
- [x] El perfil sigue cargando desde `/perfil/me`.
- [x] Lint y build sin errores.
