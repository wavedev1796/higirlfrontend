## Implementacion

### F1 - InterestsModal integrado en feed

```text
src/app/(dashboard)/feed/page.tsx
```

- Se agrega estado `interestsDismissed` (`useState(false)`).
- Condición: `showInterestsModal = !interestsDismissed && user.interestsCount < 3`.
- Modal acepta `onSuccess` (llama `refreshUser()`) y `onClose` (setea dismissed).
- El modal **no bloquea** la navegación — puede cerrarse sin completar intereses.

```tsx
const [interestsDismissed, setInterestsDismissed] = useState(false);
const showInterestsModal = !interestsDismissed && (user?.interestsCount ?? 0) < 3;

{showInterestsModal && (
  <InterestsModal
    onSuccess={() => refreshUser()}
    onClose={() => setInterestsDismissed(true)}
  />
)}
```

### F2 - Layout del dashboard corregido

```text
src/styles/layouts.css
```

El layout del dashboard sigue el patrón de tres columnas:

```text
.dashboard-container
  ├── .dashboard-sidebar  (comunidad / recomendaciones)
  ├── .dashboard-feed     (contenido principal)
  └── .dashboard-aside    (perfil / eventos)
```

Se corrigieron estilos de `.pro-card` para consistencia de spacing y radios.
Se estandarizó `.activity-list` y `.activity-item`.

### F3 - Mejoras de accesibilidad en formularios

```text
src/styles/components.css
```

- Inputs con `:focus-visible` heredado de `base.css` (outline brand-strong).
- `.field-grid` con breakpoint corregido a `480px` (ver Fase 3 — breakpoints).
- Labels visibles en todos los campos — no placeholder-only.
- Estados `disabled` con opacity 0.5 + `cursor: not-allowed`.
