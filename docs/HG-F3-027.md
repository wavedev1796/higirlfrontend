# HG-F3-027 - Integracion de foros y tipografia unificada

## Resumen

Se reemplazo el contenido reservado del feed por el modulo real de foros del
backend TICKET-018. Ademas, toda la interfaz usa ahora una unica familia
tipografica: Poppins.

## Contrato de backend integrado

- `GET /api/v1/feed?page=1&limit=10&interesId=2`
- `POST /api/v1/publicaciones`
- `POST /api/v1/publicaciones/:id/likes`
- `DELETE /api/v1/publicaciones/:id`

El frontend respeta la paginacion, el orden descendente del feed, el filtro por
interes, el toggle de likes y la autorizacion de borrado por autora o admin. La
exclusion de publicaciones de usuarias bloqueadas queda aplicada por el backend.

## Alcance implementado

- Listado real de publicaciones persistidas.
- Creacion de publicaciones de hasta 2000 caracteres.
- Tema opcional tomado del catalogo real de intereses.
- Filtro de feed por interes.
- Paginacion incremental mediante `Ver mas publicaciones`.
- Like optimista con sincronizacion de la respuesta real.
- Eliminacion con dialogo de confirmacion para autora o administradora.
- Estados de carga, vacio y error con opcion de reintento.
- Fotos de perfil o iniciales como fallback.
- Diseno responsive para escritorio y movil.
- Eliminacion de Lora y adopcion global de Poppins en cuerpo, titulos,
  formularios y controles.

## Criterios verificados

- [x] No se usa data quemada para publicaciones, intereses, autoras o likes.
- [x] El feed consume el contrato del backend TICKET-018.
- [x] Las acciones de crear, reaccionar, filtrar, paginar y eliminar estan
      conectadas a la API.
- [x] Toda la tipografia usa la misma familia.
