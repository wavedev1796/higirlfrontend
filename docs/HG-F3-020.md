# HG-F3-020 - Las notificaciones llegan a la campana

## Resumen

Las notificaciones no aparecían en la campana del header: había que entrar a la
sección Conexiones para enterarse de una solicitud recibida. La causa principal
era de datos/entorno (la tabla `notificaciones` no existía en la base de datos),
no del frontend. Adicionalmente se mejoró el refresco de la campana para que una
notificación recién recibida aparezca sin esperar el sondeo de 60s.

## Causa raíz

Diagnóstico por capas contra el backend en ejecución:

1. `GET /api/v1/notificaciones` → `404` (el backend corría un build viejo sin la
   ruta registrada) → se reconstruyó y reinició el backend.
2. Tras el reinicio → `500 relation "notificaciones" does not exist`.
3. `npm run migration:show` mostró la migración `AddNotificacionesTable1781280000004`
   como **pendiente** (`[ ]`). La tabla nunca se había creado.

El frontend (hook `useNotifications`, `NotificationBell` con su badge `9+`) y el
backend (controller/servicio de notificaciones) ya estaban correctos; solo
faltaba que la tabla existiera.

## Solución

### Backend / entorno (operativo, sin cambio de código)

```powershell
npm run migration:run   # crea la tabla notificaciones + índice + FK
```

Verificado end-to-end vía API: al crear una conexión se inserta la notificación
(`201`) y `GET /notificaciones` la devuelve con `leido: false`.

### Frontend (mejora de refresco)

El layout del dashboard no se remonta al navegar entre páginas, así que la
campana solo se actualizaba con el poll de 60s. Se agregó un refresco al volver
el foco a la pestaña (mismo patrón que ya usa `useConnections`), para que una
notificación recién recibida aparezca de inmediato al regresar a la app.

## Archivos Modificados

```text
src/features/notifications/hooks/useNotifications.ts   (refresco al foco de ventana)
```

Backend: no hubo cambio de código; solo se corrió la migración ya existente
(`src/migrations/1781280000004-AddNotificacionesTable.ts`).

## Criterios de Aceptación

- [x] Al recibir una solicitud, la campana muestra el badge con el número.
- [x] La notificación aparece sin tener que entrar a Conexiones.
- [x] Al volver el foco a la pestaña, la campana se refresca sin esperar 60s.

## Pruebas Realizadas

```powershell
npm.cmd run lint
npm.cmd run build
```

Resultado:

- Lint sin errores ni warnings.
- Build de Next.js generado correctamente.
- Verificación funcional vía API (crear conexión → notificación listada).

## Nota de despliegue

En cualquier entorno donde las notificaciones no aparezcan, verificar primero que
la migración `AddNotificacionesTable` esté aplicada (`npm run migration:show`).
