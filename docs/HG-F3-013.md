# HG-F3-013 - Auditoria UX/UI Fase 1: Sistema de Diseño y Tokens CSS

**Rama:** `feature/edu-2026-dev`
**Sprint:** 3
**Estado:** Completado
**Fecha:** 2026-06-28

---

## Resumen

Se realizó una auditoría completa del sistema de diseño del frontend de Hi Girl.
El objetivo fue consolidar todos los valores de color, tipografía, espaciado,
radios, z-index y transiciones en un único archivo de tokens CSS como fuente
de verdad, eliminando valores hardcodeados dispersos en el código.

---

## Objetivo

- Centralizar el sistema de diseño en `tokens.css` con CSS custom properties.
- Garantizar que la paleta de marca sea consistente con las guías oficiales de Hi Girl.
- Establecer escalas sistemáticas para espaciado, radios y z-index.
- Agregar soporte de accesibilidad para `prefers-reduced-motion`.

### T2 - Glassmorphism

```text
--glass-bg:        rgba(255, 255, 255, 0.85)
--glass-border:    rgba(255, 255, 255, 0.6)
--glass-highlight: rgba(255, 255, 255, 0.8)
```

Usado en cards, sidebar y modales con `backdrop-filter: blur`.

### T6 - Transiciones

```text

--transition-bounce: 400ms cubic-bezier(0.175, 0.885, 0.32, 1.275)
```

### T7 - Animaciones globales

Keyframes definidos en `tokens.css`:

- `fadeInUp` — entrada con opacity + translateY
- `float` — levitación suave (ej. logo)
- `pulse-glow` — pulso de box-shadow rosado
- `shimmer` — skeleton loading
- `spin` — spinner de carga

### T8 - Tipografía en tokens

```css
/* tokens.css — @theme inline */
--font-heading: var(--font-poppins);
--font-body:    var(--font-lora);
```

### T9 - base.css

Resets y estilos base:

- `box-sizing: border-box` global.
- `font-family` del body apunta a `var(--font-lora)`.
- Headings `h1–h6` y clases `.brand-lockup`, `.eyebrow`, `.primary-button`, `.secondary-button` apuntan a `var(--font-poppins)`.
- `:focus-visible` con outline de 2px en `--brand-strong` para accesibilidad de teclado.
- `::selection` con fondo `--brand`.
- `prefers-reduced-motion: reduce` neutraliza animaciones y transiciones.

## Criterios de aceptacion

- [x] Todos los valores de color del branding están en tokens CSS.
- [x] `--muted` cumple ratio WCAG AA (≥ 4.5:1).
- [x] `--error` y `--heading-dark` son tokens separados (evitar confusión semántica).
- [x] Escala de espaciado sigue grid de 4pt.
- [x] Z-index tiene escala explícita y nombrada.
- [x] `prefers-reduced-motion` cubre todas las animaciones.
- [x] Fuentes heading y body apuntan a tokens — sin valores hardcodeados.
